# База питань

Джерело правди — тематичні файли `questions/*.json`. Готовий `KinoBattleApp/questions.json`
(його читають застосунок, превʼю й сервер) **генерується** — руками його не редагуємо.

```sh
node tools/build-questions.js   # перевірити й зібрати questions.json + media/CREDITS.md
node tools/fetch-media.js       # докачати нові картинки з content/media.json
```

## Формат питання

```json
{"id": "dir-godfather", "type": "text", "difficulty": 1,
 "prompt": "Хто зняв «Хрещеного батька»?",
 "options": ["Френсіс Форд Коппола", "Мартін Скорсезе", "Браян Де Пальма", "Серджо Леоне"],
 "correctIndex": 0,
 "fact": "Його донька Софія Коппола зіграла в третій частині…"}
```

- `id` — латиниця, цифри, дефіс; **не змінюй id наявних питань** (за ними гра памʼятає, що вже показувала).
- `type`: `text`, `emoji` (емодзі в `prompt`), `frame` (кадр: `"image": "<id з media.json>"`),
  `cast` (`"cast": [{"name": "Том Генкс", "image": "actor-tom-hanks"}, …]`, 2–4 актори).
- `difficulty`: 1 — легке, 2 — середнє, 3 — складне. У матчі питання йдуть від легших до важчих.
- Рівно 4 варіанти; правильний зазвичай перший (`correctIndex: 0`) — у грі їх перемішують.
- Межі: питання ≤ 120 символів, варіант ≤ 40, факт ≤ 160. Факт обовʼязковий.

## Картинки

Лише з Wikimedia Commons і лише вільні ліцензії (суспільне надбання, CC0, CC BY, CC BY-SA) —
`tools/fetch-media.js` інші відкидає. Фото акторів береться з Wikidata (властивість P18) за іменем;
**після завантаження переглянь картинки очима** — пошук може знайти тезку або фото з підписом.

Кадри сучасних фільмів захищені авторським правом і на Commons їх майже немає, тому питання
«кадр» — про класику, що перейшла в суспільне надбання (фільми США до 1929 року й ті,
чиї автори померли понад 70 років тому).

Підпис автора показується під картинкою в грі, а повний список — на екрані «Автори фото»
й у `KinoBattleApp/media/CREDITS.md` (вимога ліцензій CC BY / CC BY-SA).
Фото людей можуть підпадати під право на зображення — перед комерційним релізом варто
проконсультуватися з юристом.
