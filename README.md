# TestLab — тестова iOS-апка на SwiftUI

Невелика навчальна апка з трьома вкладками:

- **Головна**: лічильник із вібровідгуком (значення зберігається між запусками) та інформація про пристрій.
- **Сенсори**: дані акселерометра й гіроскопа через CoreMotion, кути нахилу та «будівельний рівень» із пухирцем.
- **Нотатки**: простий список нотаток, збережений на телефоні (UserDefaults + JSON). Можна видаляти й перетягувати.

Вимоги: Mac з **Xcode 16+**, iOS 17+.

## Як запустити на своєму айфоні

1. Склонуй репозиторій на Mac і відкрий `TestLab.xcodeproj`.
2. Xcode → Settings → Accounts → додай свій Apple ID (безкоштовного акаунта достатньо).
3. Вибери ціль **TestLab** → вкладка **Signing & Capabilities**:
   - **Team**: вибери свій Apple ID (Personal Team);
   - **Bundle Identifier**: заміни `com.example.testlab` на щось унікальне, наприклад `com.<твоє-імʼя>.testlab`.
4. Підʼєднай айфон кабелем (або через ту саму Wi‑Fi мережу) і вибери його вгорі як пристрій запуску.
5. На айфоні увімкни **Developer Mode**: Налаштування → Конфіденційність і безпека → Режим розробника (телефон перезавантажиться).
6. Натисни ▶︎ (Cmd+R).
7. Під час першого запуску iOS попросить довіряти розробнику: Налаштування → Основні → VPN і керування пристроєм → твій Apple ID → «Довіряти».

> З безкоштовним акаунтом підпис діє 7 днів, після цього апку треба знову запустити з Xcode.
> У симуляторі сенсорів руху немає, тож вкладку «Сенсори» перевіряй на справжньому телефоні.

## Структура

```
TestLab.xcodeproj/     проєкт Xcode (папка TestLab підхоплюється автоматично)
TestLab/
  TestLabApp.swift     точка входу та TabView
  HomeView.swift       лічильник і дані про пристрій
  SensorsView.swift    CoreMotion і рівень
  NotesView.swift      нотатки
  Assets.xcassets      іконка та акцентний колір
```

Нові `.swift`-файли, додані в папку `TestLab/`, Xcode підхоплює сам, без ручного додавання до проєкту.
